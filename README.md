# NH Magic Eraser v5 (Red & Black True AMOLED Edition)

Offline object, person, text, and logo eraser for your photos and videos.
Built with Kotlin, Jetpack Compose, and Material 3 (`com.nh.magiceraser`, `minSdk 24`, `targetSdk 34`).

## What's new in v5
- **True AMOLED Pitch-Black & Crimson Red UI (`#000000` + `#FF1E38`)**: Zero-power pure black canvas with animated cyber-grid, rising crimson ember particles, and glowing obsidian-red glass surfaces.
- **Interactive Live AI Demo Banner**: Real-time animated split-screen scanner showcase on the Studio Home screen.
- **Flagship Studio Layout**: Rotating reactor splash screen, bento capability cards with rotating laser rings, 3-step workflow strip, and pulsing telemetry indicators.
- **Pro Image Studio**: Dual-layer glowing crimson mask strokes with live brush reticle, 1-tap Brush & Feathering preset bar, 800% pinch-zoom, and laser split-screen comparator.
- **Pro Video Studio**: Animated marching-ants target boxes, multi-region chips, dual-ring reactor progress gauge, and live frame scan HUD.
